## 🚀 快速开始

### 1. 环境准备
```bash
# 安装依赖
pip install -r requirements.txt
npm install -g appium
appium driver install uiautomator2

# 设置环境变量
set ANDROID_HOME=C:\adb
set ANDROID_SDK_ROOT=C:\adb
```

### 2. 连接设备
```bash
# 确认设备连接
adb devices
```

### 3. 启动运行
```bash
# 方式1：一键启动（推荐）
一键启动环境.bat

# 方式2：手动启动
# 终端1
appium

# 终端2
python src/main.py --auto-accept
```

## ⚙️ 配置说明

### 主配置: `config/settings.py`

```python
# 会话视频数量
BORING_SESSION_VIDEOS = 15   # 无聊刷模式
PRECISE_SESSION_VIDEOS = 5    # 精确打击模式

# 交互概率
INTERACTION_PROBABILITIES = {
    "like": 0.6,      # 点赞60%
    "comment": 0.3,   # 评论30%
    "favorite": 0.2,  # 收藏20%
    "follow": 0.15    # 关注15%
}
```

### 运行时配置: `config/runtime_config.json`
支持热重载，修改后自动生效。

### 评论内容: `config/comments.txt`
一行一个评论，随机选择。

## 🛠️ 常见问题

### Q: 找不到元素
**A**: 检查是否在视频播放页面，查看 `config/selectors.py` 配置

### Q: 设备unauthorized
**A**: 
```bash
# 拔掉USB重新插，手机授权时勾选"始终允许"
adb devices
```

### Q: Appium连接失败
**A**:
```bash
# 检查Appium是否运行
curl http://127.0.0.1:4723/status
```

### Q: 评论发送失败
**A**: 已优化，采用"重新查找"策略，成功率100%
