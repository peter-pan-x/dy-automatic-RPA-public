# 抖音RPA自动化系统 V7.2

基于Python + Appium的抖音自动化RPA系统，实现智能视频浏览、点赞、评论、收藏、关注等功能，支持视频去重、LLM智能回复、目标视频深度交互等高级功能。

**测试状态**: ✅ 所有功能100%成功（2025-12-02）

## 🚀 快速开始

### 1. 环境准备
```bash
# 安装依赖
pip install -r requirements.txt
npm install -g appium
appium driver install uiautomator2

# 设置环境变量
set ANDROID_HOME=C:\adb
set ANDROID_SDK_ROOT=C:\adb
```

### 2. 连接设备
```bash
# 确认设备连接
adb devices
```

### 3. 启动运行
```bash
# 方式1：一键启动（推荐）
start_appium.bat
run_main.bat

# 方式2：手动启动
# 终端1
appium

# 终端2
python main.py
```

## ⚙️ 配置说明

### 主配置文件: `config/config.yaml`

按模块分区配置，支持热重载：

```yaml
main:
  warmup_duration: 180      # 预热时长（秒）
  module_gap: 30           # 模块间隔（秒）

random_browse:
  probability:
    skip_video: 0.22       # 跳过概率
    comment: 0.66          # 评论概率
    favorite: 0.33         # 收藏概率

search_browse:
  target_replies: 50        # 目标评论数量
  probability:
    like: 0.66             # 点赞概率
    comment: 0.66          # 评论概率
    favorite: 0.33         # 收藏概率
  video_filter:
    min_likes: 100         # 最小点赞数
    min_comments: 5        # 最小评论数

promotion:
  products:                 # 推广产品配置
    - name: "产品A"
      keywords: ["关键词1", "关键词2"]

llm:
  use_preset: true          # 是否使用预设回复
  api_key: "your-key"       # LLM API密钥

intercept:
  keywords: ["敏感词1"]     # 评论拦截关键词
```

### 运行时配置: `config/runtime_config.json`
支持热重载，修改后自动生效。

### 评论内容: `config/comments.txt`
一行一个评论，随机选择发送。

### 搜索关键词: `config/keywords.txt`
用于搜索浏览模式的关键词列表。

## 🔧 高级功能

### 🎯 视频任务去重系统 (V7.1)
- **SQLite数据库**: 持久化存储已处理视频
- **哈希唯一标识**: 基于作者+描述+点赞数+评论数生成ID
- **智能去重**: 相同产品+相同视频ID只处理一次
- **自动清理**: 默认30天清理过期记录

### 🤖 LLM智能回复系统
- **大模型集成**: 支持多种LLM API
- **上下文理解**: 基于视频内容和评论生成回复
- **预设回复切换**: 可选择预设回复或AI生成
- **评论拦截**: 过滤敏感关键词

### 🎬 目标视频深度交互系统 (V6.0)
- **智能识别**: 评论数≥5的视为目标视频
- **播放策略**: 30-80%随机播放时长
- **评论阅读**: 逐条阅读所有评论内容
- **自然交互**: 阅读→留言→收藏的真实流程

### 📱 评论区仿真交互
- **滑动仿真**: 评论时随机滑动3-6次
- **阅读模拟**: 每条评论间隔0.5秒
- **输入优化**: 重新查找输入框避免元素过期

### 🛡️ 反检测机制
- **随机延迟**: 人性化操作间隔
- **界面适配**: 支持卡片式和传统列表
- **状态检测**: 智能判断页面状态
- **连续失败保护**: 6次失败自动退出

### 📊 数据统计与监控
- **详细统计**: 分类统计各种操作
- **性能监控**: 成功率和耗时分析
- **日志系统**: 彩色控制台+文件轮转
- **截图保存**: 关键操作截图记录

## 🛠️ 常见问题

### Q: 找不到元素
**A**: 检查是否在视频播放页面，更新 `config/selectors.py` 中的选择器配置

### Q: 设备unauthorized
**A**:
```bash
# 拔掉USB重新插，手机授权时勾选"始终允许"
adb devices
```

### Q: Appium连接失败
**A**:
```bash
# 检查Appium是否运行
curl http://127.0.0.1:4723/status
```

### Q: LLM回复失败
**A**: 检查API密钥配置，网络连接，尝试切换到预设回复模式

### Q: 视频重复处理
**A**: 去重数据库会自动记录已处理视频，重启程序或清理数据库可重置
