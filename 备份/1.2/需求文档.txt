# 抖音高仿真引流RPA项目 (V4 - 混合动力·最终版)

## 1. 项目主题
创建一个基于“混合会话模式”的抖音(Douyin)高仿真引流RPA项目。

## 2. 项目目标
开发一个高健壮性、模块化的 Python 脚本。该脚本通过“伪装会话”（无聊刷）和“攻击会话”（精准打击）的**随机交替执行**，实现高仿真的引流操作，最大限度延长项目生命周期。

## 3. 核心架构原则

1.  **健壮性 (核心优先):** 坚决保证主流程（启动、会话切换、搜索、滑动）的绝对稳定。所有功能（如评论、点赞）都是“插件”，即使失败也不能导致主流程崩溃。
2.  **模块化 (易维护):** 严格分离职责。Appium连接、底层工具、业务逻辑、任务编排必须在不同的文件中，便于单独调试和修改。
3.  **清晰结构 (易分辨):** 采用专业的项目目录结构，使文件功能一目了然。

5. 文件详细需求 (Req 1 & 3)
5.1. config/settings.py (配置中心)
Appium 配置： DOUYIN_CAPS 字典和 APPIUM_SERVER_URL。

[核心] 会话节奏控制：

SESSION_FOR_YOU_MIN_VIDEOS = 15

SESSION_FOR_YOU_MAX_VIDEOS = 25

SESSION_SEARCH_MIN_VIDEOS = 30

SESSION_SEARCH_MAX_VIDEOS = 50

[核心] 行为概率 (分状态)：

FOR_YOU_LIKE_PROB = 0.1 (无聊刷时，10% 概率点个赞)

SEARCH_LIKE_PROB = 0.8 (精准打击时，80% 概率点赞)

SEARCH_COMMENT_PROB = 0.2 (精准打击时，20% 概率评论)

SEARCH_FAVORITE_PROB = 0.15

SEARCH_FOLLOW_PROB = 0.1

仿真延迟：

WATCH_TIME_MIN = 7 (秒)

WATCH_TIME_MAX = 15 (秒)

5.2. src/app_driver.py (驱动器)
职责： 健壮性（Req 3）。

connect()：读取 settings.py，初始化 webdriver.Remote，处理连接失败的 try-except，返回 driver。

quit(driver)：安全关闭 driver。

5.3. src/core_utils.py (原子工具)
职责： 健壮性（Req 3）。

find_element_safe(driver, by, value, timeout=5)：(必须) 找不到时绝不崩溃，返回 None。

swipe_up_humanized(driver)：(必须) 带随机偏移和随机时长的仿真上滑。

send_keys_safe(driver, element, text)：(必须) 健壮的输入。

5.4. src/interactions.py (业务插件)
职责： 模块化（Req 1）。

like_current_video(driver)

comment_on_current_video(driver, comment_text)

perform_search_and_switch(driver, keyword) (执行搜索并切换到视频Tab)

dismiss_popups_if_present(driver) (健壮性：每次循环前都调用)

[健壮性]：所有这些函数都必须使用 core_utils.py 里的 find_element_safe。如果 find 失败，函数应安静地 return False，而不是抛出异常。

5.5. src/tracker.py (统计器)
InteractionTracker class，负责所有计数和 display_summary()。

5.6. src/task_manager.py (灵魂：状态机)
职责： 混合会话逻辑。

class TaskManager:

__init__(self, driver)：

self.driver = driver

self.tracker = Tracker()

self.state = 'STATE_FOR_YOU' (启动时总是先“无聊刷”)

self.keywords_list = self._load_keywords()

self.comments_list = self._load_comments()

_load_keywords() / _load_comments()：从 config/ 读取文件。

run_main_loop(self)：(主循环)

while True:

if self.state == 'STATE_FOR_YOU':

self._run_for_you_session()

self.state = 'STATE_SEARCH' (切换状态)

elif self.state == 'STATE_SEARCH':

self._run_search_session()

self.state = 'STATE_FOR_YOU' (切换状态)

self.tracker.display_summary() (每次会话结束打印一次报告)

_run_for_you_session(self)：(迷魂汤模式)

for i in range(count):

(如果评论，则 random.choice(self.comments_list))

5.7. src/main.py (启动器)
职责： 保持简洁。
