## 📁 日志文件说明

### **logs/douyin_rpa_YYYYMMDD.log** (运行日志)

**用途**: 记录程序运行的全部过程

**内容包括**:
- 程序启动信息
- 环境检查详情
- 组件初始化过程
- 任务执行日志
- 正常的操作记录
- 警告信息

**示例文件名**: `logs/douyin_rpa_20251115.log`

**特点**:
- 每天一个文件
- 自动滚动（单个文件超过10MB会自动分割）
- 保留最近5个备份文件

---

### **logs/error.log** (错误日志)

**用途**: 专门记录错误和异常

**内容包括**:
- 所有ERROR级别的日志

**特点**:

- 自动滚动（单个文件超过10MB会自动分割）

## 🐛 程序闪退后怎么办

### **立即操作（3步）：**

#### **步骤1: 查看错误日志**

```powershell
python view_last_error.py
```

或者：

```powershell
Get-Content logs\error.log -Tail 100
```

#### **步骤2: 找到关键信息**

在日志中查找：
- `ERROR` - 错误信息
- `CRITICAL` - 严重错误
- `Exception` - 异常类型
- `Traceback` - 堆栈跟踪

**示例**:
```
2025-11-15 14:23:45 - douyin_rpa - [ERROR] - main.py:156 - initialize_components()
组件初始化失败: 'NoneType' object has no attribute 'start_session'

Traceback (most recent call last):
  File "src/main.py", line 150, in initialize_components
    self.driver = app_driver.connect(max_retries=3)
  File "src/app_driver.py", line 45, in connect
    driver.start_session()
AttributeError: 'NoneType' object has no attribute 'start_session'
```

#### **步骤3: 根据错误信息排查**

常见错误类型：

| 错误信息 | 可能原因 | 解决方法 |
|---------|---------|---------|
| `connection refused` | Appium服务未运行 | 启动Appium: `appium` |
| `device not found` | 设备未连接 | 检查USB连接和授权 |
| `ModuleNotFoundError` | 缺少依赖 | `pip install -r requirements.txt` |
| `AttributeError: 'NoneType'` | 对象初始化失败 | 检查前序步骤是否成功 |
| `Timeout` | 操作超时 | 检查网络或设备响应 |

## 📊 日志级别说明

日志按重要性分为5个级别：

| 级别 | 说明 | 何时出现 | 颜色 |
|------|------|---------|------|
| **DEBUG** | 调试信息 | 详细的内部操作 | 白色 |
| **INFO** | 一般信息 | 正常运行过程 | 绿色 |
| **WARNING** | 警告 | 可能的问题，但程序继续运行 | 黄色 |
| **ERROR** | 错误 | 出现错误，某个操作失败 | 红色 |
| **CRITICAL** | 严重错误 | 致命错误，程序可能崩溃 | 红底白字 |
