## 🛠️ 环境准备：详细安装步骤

### 第一步：安装Python

1. **下载Python**
   - 访问官网：https://www.python.org/downloads/
   - 下载 **Python 3.9或更高版本**（推荐3.11）
   - 选择适合您系统的版本（Windows x86-64 executable installer）

2. **安装Python**
   - 运行下载的安装包
   - **重要：勾选"Add Python to PATH"**
   - 点击"Install Now"完成安装

3. **验证安装**
   ```bash
   # 打开命令提示符（Win+R，输入cmd，回车）
   python --version
   # 应该显示：Python 3.9.x 或更高版本
   ```

### 第二步：安装项目依赖

1. **打开命令提示符**
   - 按 `Win + R`
   - 输入 `cmd`
   - 按回车

2. **进入项目目录**
   ```bash
   # 假设项目在桌面上
   cd C:\Users\admin\Desktop\onebutton\douyin���autoclient

   # 验证目录
   dir
   # 应该看到 src、config、logs 等文件夹
   ```

3. **安装依赖包**
   ```bash
   pip install -r requirements.txt
   ```
   **如果出现错误，尝试：**
   ```bash
   python -m pip install -r requirements.txt
   ```

### 第三步：安装ADB驱动

1. **下载ADB工具**
   - 访问：https://developer.android.com/studio/releases/platform-tools
   - 下载 "Platform Tools for Windows"

2. **解压并配置**
   - 解压到 `C:\adb`
   - 添加到系统PATH：
     - 右键"此电脑" → 属性 → 高级系统设置 → 环境变量
     - 在系统变量中找到"Path"，点击编辑
     - 点击新建，输入 `C:\adb`

3. **验证ADB**
   ```bash
   adb version
   # 应该显示ADB版本信息
   ```

## 📱 设备配置：Android手机设置

### 第一步：开启开发者选项

1. **打开设置**
   - 进入手机的"设置"应用

2. **找到关于手机**
   - 通常在"系统"或"关于手机"选项中

3. **开启开发者选项**
   - 连续点击"版本号"7次
   - 会看到"您已处于开发者模式"的提示

### 第二步：开启USB调试

1. **进入开发者选项**
   - 返回设置主页
   - 找到"开发者选项"（通常在"系统"中）

2. **开启关键选项**
   - ✅ 开启"开发者选项"总开关
   - ✅ 开启"USB调试"
   - ✅ 开启"USB安装"
   - ✅ 开启"USB调试（安全设置）"

### 第三步：连接电脑测试

1. **连接手机和电脑**
   - 使用原装或优质USB数据线
   - 连接时选择"传输文件"模式

2. **授权调试**
   - 手机会弹出"允许USB调试吗？"
   - **勾选"始终允许这台计算机进行调试"**
   - 点击"确定"

3. **验证连接**
   ```bash
   adb devices
   # 应该显示类似：
   # List of devices attached
   # ABC123456	device
   ```
   **如果显示"unauthorized"，重新插拔USB线，重新授权**

## ⚙️ 配置修改：个性化设置

### 1. 实时配置修改（推荐）

程序运行时会生成 `config/runtime_config.json` 文件，您可以**实时修改**，无需重启程序！

```json
{
  "behavior": {
    "for_you_like_prob": 0.1,      // 推荐页面点赞率（0.1 = 10%）
    "search_like_prob": 0.8,       // 搜索页面点赞率（0.8 = 80%）
    "search_comment_prob": 0.2,    // 搜索页面评论率（0.2 = 20%）
    "search_favorite_prob": 0.15,  // 收藏率（0.15 = 15%）
    "search_follow_prob": 0.1      // 关注率（0.1 = 10%）
  },
  "sessions": {
    "for_you_min_videos": 15,      // 推荐页面最少视频数
    "for_you_max_videos": 25,      // 推荐页面最多视频数
    "search_min_videos": 30,       // 搜索页面最少视频数
    "search_max_videos": 50        // 搜索页面最多视频数
  },
  "anti_detection": {
    "daily_active_hours": [9, 10, 11, 14, 15, 16, 19, 20, 21],
    // 每日活跃时间（24小时制），可以修改
    "min_break_minutes": 5,        // 最短休息时间（分钟）
    "max_break_minutes": 20        // 最长休息时间（分钟）
  }

```

**修改技巧：**
- 降低点赞率：`0.8` → `0.5`
- 增加视频数量：`25` → `40`
- 调整活跃时间：添加或删除小时数
- **修改后保存文件，程序会在下次操作时自动使用新配置！**

## ❌ 故障排除：常见问题解决

### 问题1：提示"设备未连接"
**解决方案：**
1. 检查USB线是否插好
2. 重新开启USB调试
3. 重新授权USB调试（拔插USB线）
4. 检查ADB驱动是否安装
5. 尝试不同的USB端口

**验证命令：**
```bash
adb devices
# 应该显示您的设备，状态为"device"
```

### 问题2：提示"Appium Server未运行"
**解决方案：**
1. 确保Appium窗口没有关闭
2. 检查Appium是否显示错误信息
3. 重启Appium服务
4. 检查4723端口是否被占用

**验证命令：**
```bash
curl http://127.0.0.1:4723/status
# 应该返回JSON格式的状态信息
```

### 问题3：找不到抖音应用
**解决方案：**
1. 确保手机上已安装抖音
2. 检查抖音是否是最新版本
3. 修改配置中的包名（如果使用抖音极速版等）

### 问题4：程序运行中出错
**解决方案：**
1. 查看logs/app.log文件中的详细错误信息
2. 检查手机屏幕是否正常亮起
3. 确保手机没有弹出其他对话框
4. 重启程序尝试

### 问题5：依赖安装失败
**解决方案：**
```bash
# 使用升级的pip
python -m pip install --upgrade pip

# 清除缓存重新安装
pip install -r requirements.txt --no-cache-dir

# 如果还有问题，逐个安装
pip install Appium-Python-Client
pip install requests
pip install psutil
```
