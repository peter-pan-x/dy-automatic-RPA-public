## 🛠️ 手动配置步骤

### 1. 安装Python依赖

```bash
pip install -r requirements.txt
```

如果速度慢，使用国内镜像：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 2. 安装ADB工具

**Windows**:
1. 下载 Android Platform Tools：https://developer.android.com/tools/releases/platform-tools
2. 解压到 `C:\adb\platform-tools\`
3. 添加到系统PATH：`C:\adb\platform-tools`
4. 验证安装：`adb version`

**设置环境变量**（重要）：
```bash
# PowerShell
$env:ANDROID_HOME="C:\adb"
$env:ANDROID_SDK_ROOT="C:\adb"

# CMD
set ANDROID_HOME=C:\adb
set ANDROID_SDK_ROOT=C:\adb
```

### 3. 安装Node.js和Appium

1. **安装Node.js**: https://nodejs.org/（选择LTS版本）

2. **安装Appium**:
```bash
npm install -g appium
```

3. **安装UIAutomator2驱动**:
```bash
appium driver install uiautomator2
```

4. **验证安装**:
```bash
appium --version
```

### 4. 连接Android设备

1. 使用**数据线**（非充电线）连接手机到电脑
2. 手机开启**开发者选项**和**USB调试**
3. 手机弹出"允许USB调试"提示时，点击**允许**并勾选**始终允许**
4. 验证连接：`adb devices`

## 📱 华为手机特殊配置

华为手机有独特的安全机制，需要额外配置。

### ⚠️ 必须完成的设置

#### 1. 退出"纯净模式"（最关键）

"纯净模式"会严格限制第三方应用的安装和运行。

**操作步骤**：
1. 进入手机 **"设置"**
2. 搜索并进入 **"纯净模式"**
3. 选择 **"退出纯净模式"**
4. 按照屏幕提示完成退出

#### 2. 开启"允许HDB连接设备"

**操作步骤**：
1. 进入 **"设置"** → **"开发者选项"**
2. 找到 **"允许HDB连接设备"**
3. 开启此选项

#### 3. 关闭"监控ADB安装应用"

**操作步骤**：
1. 进入 **"设置"** → **"开发者选项"**
2. 找到 **"监控ADB安装应用"**
3. 将其设置为 **"关闭"**

#### 4. 关闭应用市场安全检查

**操作步骤**：
1. 打开 **"华为应用市场"**
2. 进入 **"我的"** 页面
3. 点击右上角的 **"设置"** 图标
4. 找到并关闭 **"安装时病毒扫描"**

#### 5. 授予Appium辅助应用权限

当Appium Settings安装界面弹出时：
- **关闭** "开启增强防护"开关（默认关闭，保持关闭）
- **勾选** "不再提示"
- 点击 **"仍然安装"** 或 **"允许安装"**

#### 6. 设置USB模式

**操作步骤**：
1. 进入 **"设置"** → **"开发者选项"**
2. 找到 **"选择USB配置"**
3. 选择 **"MTP（文件传输）"**
4. 开启 **"仅充电模式下允许ADB调试"**

### 🔄 完成配置后重启手机

完成以上所有设置后，**强烈建议重启手机**，以确保所有更改生效。

## 🐛 常见问题排查

### ❌ 问题1: adb devices显示空列表

**可能原因**：
1. USB线缆为充电线，非数据线
2. USB调试未开启
3. ADB驱动未安装
4. 华为手机未开启"允许HDB连接"

**解决方案**：
1. 更换为**数据线**（最常见原因）
2. 确认手机已开启USB调试
3. 重启ADB服务：
   ```bash
   adb kill-server
   adb start-server
   adb devices
   ```
4. 华为手机：开启"允许HDB连接设备"

### ❌ 问题2: Appium辅助应用重复安装

**现象**：每次启动程序都提示安装 `io.appium.settings`

**原因**：华为手机安全策略拦截

**解决方案**：
1. 退出"纯净模式"
2. 关闭"增强防护"
3. 手动授予权限：
   ```bash
   adb shell pm grant io.appium.settings android.permission.WRITE_SETTINGS
   adb shell pm grant io.appium.settings android.permission.ACCESS_FINE_LOCATION
   ```
4. 在 `config/runtime_config.json` 中确认已设置：
   ```json
   "skipServerInstallation": true,
   "skipDeviceInitialization": true,
   "autoGrantPermissions": true
   ```

### ❌ 问题3: ModuleNotFoundError

**现象**：`ModuleNotFoundError: No module named 'appium'`

**解决方案**：
```bash
pip install -r requirements.txt
```

### ❌ 问题4: Appium服务未运行

**现象**：`[WARN] Appium服务未运行`

**解决方案**：
1. 打开新的命令行窗口
2. 运行 `appium`
3. 保持该窗口开启
4. 在另一个窗口运行RPA程序

或使用项目提供的启动脚本：
- 双击 `快速启动.bat`
- 选择选项 [4] 启动Appium服务

### ❌ 问题5: UnicodeEncodeError

**现象**：`UnicodeEncodeError: 'gbk' codec can't encode character`

**解决方案**：
已在代码中修复，如仍出现，尝试：
```bash
# PowerShell
$env:PYTHONIOENCODING="utf-8"

# CMD
set PYTHONIOENCODING=utf-8
```

### ❌ 问题6: Android SDK环境变量未设置

**现象**：`Neither ANDROID_HOME nor ANDROID_SDK_ROOT environment variable was exported`

**解决方案**：
设置环境变量（每次打开新终端都需要设置，或添加到系统环境变量）：
```bash
# PowerShell
$env:ANDROID_HOME="C:\adb"
$env:ANDROID_SDK_ROOT="C:\adb"

# CMD
set ANDROID_HOME=C:\adb
set ANDROID_SDK_ROOT=C:\adb
```

## 🎯 推荐工作流程

### 首次配置

```bash
# Step 1: 检查当前环境
python check_environment.py

# Step 2: 自动修复
python auto_fix_environment.py

# Step 3: 手动安装剩余组件（如有需要）

# Step 4: 再次检查确认

# Step 5: 如果一切正常，启动程序

```

```bash
# 方法1: 使用快速启动脚本

# 方法2: 手动启动
# 终端1: 启动Appium
appium

# 终端2: 启动RPA
python src/main.py --auto-accept
```
